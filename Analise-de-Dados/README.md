# Análise Climática do Estado do Rio de Janeiro

Projeto de análise exploratória de dados utilizando Python para limpeza, tratamento e visualização de dados meteorológicos das estações do estado do Rio de Janeiro.

Tecnologias:

Python
Pandas
Matplotlib

Principais análises:

Temperatura máxima, mínima e média por estação.
Chuva acumulada por estação.
Maior rajada de vento.
Temperatura média por mês.
Visualização dos resultados por meio de gráficos.


🔗 Repositório: https://github.com/vivianavelino/clima-RJ---analise-de-dados
